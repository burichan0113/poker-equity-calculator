# Texas Hold'em Equity Calculator

A desktop Texas Hold'em Equity Calculator built with Python and Tkinter.

This application calculates the equity of two specific hands using Monte Carlo simulation powered by PokerKit.

---

## Features

### ✅ Preflop Equity Calculator

- Select Hero hand
- Select Opponent hand
- Optional Board cards
- Duplicate card prevention
- Monte Carlo equity calculation
- Visual equity bar
- Card palette interface
- Keyboard shortcuts

## Installation

Clone the repository

```bash
git clone https://github.com/burichan0113/poker-equity-calculator.git
cd poker-equity-calculator
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
